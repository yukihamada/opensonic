What is Soluna

Soluna とは

ライブ・フェス・日常のBGMをリアルタイム共有する音声プラットフォーム。Macから音楽を配信し、世界中のiPhone・ブラウザ・スピーカーで受信。オープンソース（MITライセンス）。

🔊

リアルタイム音声配信

Macから音楽を配信、どこでも受信。P2Pメッシュ + WANリレーで低遅延配信。

🎵

チャンネル

66チャンネル、646曲のプレイリスト。sunset-chill、tokyo-nights、deep-focusなど、シーンに合わせて選択。

🌐

P2P + WAN

ローカルネットワークもインターネット越えも。relay.solun.art 経由で世界中から受信可能。

🔨

SDK

あなたのアプリにも組み込める。Swift SDKでiOS / macOSアプリに音声受信機能を追加。
