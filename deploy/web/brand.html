01 / Logo

Logo Marks

Soluna uses two distinct marks. Each serves a specific purpose and context. Never interchange them arbitrarily.

Primary Mark — 6A Frequency Bars

Seven vertical equalizer bars in a cyan-to-pink-to-amber gradient. The default representation of Soluna.

Secondary Mark — 6D Circular EQ

Twelve radial bars arranged in a circle with a pink-to-amber gradient. Ideal for motion contexts.

Clear Space & Minimum Size

Maintain clear space equal to the height of one bar (denoted as x) on all sides. This ensures the mark breathes and retains its impact.

02 / Usage

When to Use Each Mark

The two marks serve distinct purposes. Choose based on context and medium.

6A — Primary Mark

  • App icon and favicon
  • Website header and navigation
  • Print materials and business cards
  • Merchandise and apparel
  • Press kits and editorial use
  • Splash screens

6D — Secondary Mark

  • Loading and buffering indicator
  • In-app badge and achievement icon
  • Animated transitions
  • Social media profile picture
  • Watermark on audio visualizations
  • Animated stickers and emoji

Do's and Don'ts

✓ Use on dark backgrounds
✓ Use on light backgrounds
✗ Don't rotate the mark
✗ Don't desaturate or recolor
✗ Don't place on clashing gradients
✗ Don't stretch or distort

05 / Animations

Motion Language

Motion brings the Soluna marks to life. Each animation is purposeful, smooth, and never distracting.

6A Equalizer Bounce

Bars bounce independently to simulate a live equalizer.

6D Circular Pulse

Slow rotation with pulsing radial bars. Hypnotic and ambient.

6D Loading Spinner

Fast rotation, staggered fade. Use for buffering and loading states.

6A Bounce Animation (CSS)

@keyframes eq-bounce {
  0%, 100% { transform: scaleY(1); }
  50%      { transform: scaleY(0.4); }
}

.bar {
  width: 10px;
  border-radius: 5px;
  animation: eq-bounce 1.4s ease-in-out infinite;
}

/* Stagger each bar */
.bar:nth-child(1) { animation-delay: 0s; }
.bar:nth-child(2) { animation-delay: 0.15s; }
.bar:nth-child(3) { animation-delay: 0.3s; }
.bar:nth-child(4) { animation-delay: 0.45s; }
.bar:nth-child(5) { animation-delay: 0.6s; }
.bar:nth-child(6) { animation-delay: 0.75s; }
.bar:nth-child(7) { animation-delay: 0.9s; }

6D Circular Pulse (CSS)

@keyframes slow-rotate {
  to { transform: rotate(360deg); }
}

@keyframes radial-pulse {
  0%, 100% { opacity: 1; }
  50%      { opacity: 0.35; }
}

.mark-6d-inner {
  animation: slow-rotate 12s linear infinite;
}

.radial-bar {
  animation: radial-pulse 1.6s ease-in-out infinite;
}

/* Stagger each of the 12 bars */
.radial-bar:nth-child(n) {
  animation-delay: calc(var(--i) * 0.13s);
}

6D Loading Spinner (CSS)

@keyframes spinner-fade {
  0%, 100% { opacity: 1; }
  50%      { opacity: 0.15; }
}

.spinner-6d-inner {
  animation: slow-rotate 1.2s linear infinite;
}

.s-bar {
  animation: spinner-fade 1.2s linear infinite;
  animation-delay: calc(var(--i) * 0.1s);
}
