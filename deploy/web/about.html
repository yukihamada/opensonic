テーゼ

音楽体験のインフラを再発明する

SOLUNAは単なる音楽配信サービスではない。音が鳴る場所から聴く場所まで、 その間にある全てのレイヤー — 配信・同期・決済・権利管理 — をオープンソースのプロトコルで置き換えるプロジェクト。

Spotify / Apple Musicが「音楽をファイルとして配る」モデルなのに対して、 SOLUNAは「音楽体験そのものをリアルタイムで共有する」モデル。

ハイブリッドフェス

物理会場1,000人 + オンライン10万人が同じDJセットをゼロレイテンシーで共有。P2Pスウォームで配信コストはほぼゼロ。東京・LA・ベルリンの3会場で同時開催、完全同期のグローバルフェスも。スマホ1台でどこでもSOLUNAチャンネルを開設すれば、バー、ビーチ、公園が即座にサテライト会場に。

アーティストエコノミー

サブスク脱却とDJのマネタイズ

Spotifyの0.003$/再生ではなく、リスナー数 x 時間のリアルタイムロイヤリティ。1万人が1時間聴けば、その場で権利者に分配。選曲とミックスという「キュレーション」に対して直接課金 — チップ、サポート、チャンネル購読の3層。アーティストがSOLUNAチャンネルを持つだけで、配信・課金・権利管理が全て完結。

日常のオーディオインフラ

日常のオーディオインフラ

家中のスピーカーを5ms以下で同期 — Sonos/AirPlayの代替だがオープンソースで無料。店舗がSOLUNAチャンネルを開設すれば、著作権検出+自動課金でJASRACの申請が不要に。誰でもグローバルな「ラジオ局」を開設でき、リスナーがP2Pで配信を支えるのでサーバー代ゼロで100万人にリーチ。

分散著作権検出

リスナー側分散フィンガープリント検出

リスナーのデバイスが受信中の音声から30秒ごとにフィンガープリント（64bitハッシュ）を生成し、リレーサーバーに送信。複数リスナーの合意アルゴリズムで楽曲を自動特定し、権利者にリアルタイムで分配。送信者の負荷はゼロ、リスナーが増えるほど検出精度が向上するP2P型の仕組み。中央集権的な監視サーバーではなく、ネットワーク全体で著作権を保護する — 聴くだけで著作権保護に貢献できる新しいモデル。

プラットフォーム戦略

ハードウェア統合とプラットフォーム

オープンソース = 採用障壁ゼロ。スピーカー・DJ機器メーカーがSOLUNAプロトコルをネイティブ実装可能。Pioneer DJ / Denonとの統合で、DJ機器から直接SOLUNAネットワークに配信。CarPlay / Android Auto経由で、運転中もリアルタイムチャンネルに参加。

ビジネスモデル

持続可能な収益構造

全トランザクションの10%がプラットフォーム手数料（DJとアーティストの取り分を最大化）。カスタムチャンネル名の年間販売、イベントへのSOLUNAインフラライセンス、SOLUNA対応スピーカーの認証プログラム。
