Features

⚡

Ultra-Low Latency

Sub-millisecond latency on wired networks. Perfect for live performance and monitoring.

🔄

PTP Synchronization

IEEE 1588-2008 (PTPv2) ensures sample-accurate sync across all devices.

📶

WiFi Ready

Adaptive streaming with FEC for reliable wireless audio.

🔗

AES67 Compatible

Interoperate with Dante, Ravenna, and other AES67 devices.

🌐

Web Control

Built-in web UI, REST API, and WebSocket for easy integration.

🔒

Secure

Optional DTLS encryption for sensitive audio streams.
