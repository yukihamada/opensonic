ネットワークオーディオ

LAN内もインターネット越しも。プロ品質の双方向オーディオストリーミング。同期再生、超低遅延ジャムセッション、WANリレー対応。1,000ユーザーまで完全無料。

ダウンロード GitHubで見る

2つのモード、1つのプラットフォーム

用途に合わせてモードを切り替え。同期再生とリアルタイムジャムセッション、どちらもこれひとつで。

🔄

Sync Mode

マルチルーム同期

PTP (IEEE 1588) ベースの高精度同期で、複数のスピーカーからサンプル精度の同時再生を実現。WANリレー経由でインターネット越しの同期も可能。

  • マルチルーム同期再生
  • PTPv2によるサンプル精度の同期
  • FEC付きで安定した配信
  • WANリレーでグローバル同期
  • ホームオーディオ / 商業施設BGMに最適
🎸

Jam Mode

超低遅延 ~20ms

双方向フルデュプレックス通信で、離れた場所にいるミュージシャンともリアルタイムにジャムセッション。iPhoneのマイクから直接送信も。

  • 超低遅延 約20ms (LAN内)
  • 双方向フルデュプレックスオーディオ
  • iOSマイク送信 (TX) 対応
  • P2Pリレーで近くのデバイスと自動接続
  • バンド練習 / リモートセッションに最適

機能

⚡

超低遅延 ~20ms

Jam Modeで約20msの超低遅延を実現。リアルタイムの演奏やモニタリングに最適。

🔄

PTP同期

IEEE 1588-2008 (PTPv2)により、Sync Modeで全デバイス間のサンプル精度同期を実現。

🔀

双方向オーディオ

フルデュプレックス対応。一方向ストリーミングだけでなく、双方向リアルタイム通信でジャムセッションやコラボレーションが可能。

🌍

WANリレー

インターネット越しにオーディオを中継。UDPリレーサーバーでNAT超えも自動。世界中どこからでも接続。

📡

チャンネル

チャンネル名でグループ分け。同じチャンネルのデバイスが自動で接続。カスタム名は年額¥1,000で取得可能。

🤝

P2Pリレー

近くのデバイス同士は自動でP2P接続。1台がマルチキャスト受信し、周囲のデバイスにリレー転送。

📶

WiFi対応

FEC付き適応ストリーミングで信頼性の高いワイヤレスオーディオ。

🔗

AES67互換

Dante、Ravenna等のAES67機器と相互運用可能。

🎤

マイク送信

iPhoneのマイクから直接オーディオを送信。TX/RX両対応で、スマホがトランスミッターにもレシーバーにも。

🔒

セキュア

グループパスワード保護、チャンネル所有権管理。機密ストリーム向けDTLS暗号化にも対応。
