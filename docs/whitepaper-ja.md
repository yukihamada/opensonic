# Soluna: 音楽の電力網

**Open Sonic Transport Protocol (OSTP) とサブスクリプションモデルによる透明な音楽配信**

株式会社イネブラ (Inebra Inc.)
2026年3月19日 — v0.11.0

---

## 要旨

音楽産業は壊れている。Spotifyは1再生あたり$0.003をアーティストに支払い、リスナーは何も所有せず、再生回数は自己申告で不正が横行する。

Solunaはこの3つの問題を同時に解決する:

1. **Proof of Listen (PoL)** — 暗号学的に検証可能な再生証明
2. **Relay Network** — 音声中継によるP2P配信ネットワーク
3. **ファンランク** — 聴くほどファンランクが上がり、特典が解放される

これらはアプリケーション層ではなく**プロトコル層**で実装される。電力網が発電所と家庭を結ぶように、Solunaは音楽のプロトコルインフラとして機能する。

---

## 1. 問題

### 再生カウントは嘘をつく

Spotifyの再生回数は同社のサーバーが報告する。第三者による検証手段がない。Bot farmによる不正再生は年間$10億規模の問題とされる。

### アーティストは搾取されている

ストリーミング収益の約70%がレーベルとプラットフォームに吸収される。インディーズアーティストが音楽で生計を立てるには月間100万再生が必要。

### 収益分配が不透明

アーティストに支払われる金額の根拠が不透明で、プラットフォームの自己申告に依存している。第三者が監査できる仕組みがない。

---

## 2. 解決策

### 2.1 OSTP — 音声パケットにルールを埋め込む

OSTP（Open Sonic Transport Protocol）はRTP [RFC 3550] を拡張したUDP/QUICベースの音声配信プロトコルである。特徴:

- **24バイトヘッダ**: RTP(12B) + 拡張(4B) + OSTP(8B)。各パケットにstream_id, sequence, media_timestampを含む
- **LAN**: UDPマルチキャスト（0ms追加遅延）
- **WAN**: QUIC Unreliable Datagram [RFC 9221]（TLS 1.3暗号化、コネクション移行）
- **スケール**: P2P Swarm で30億リスナーまで拡張可能

### 2.2 Proof of Listen

リスナーのデバイスが受信パケットからハッシュチェーンを構築する:

```
genesis = SHA-256("soluna:pol:v1:" || channel_name)
tip[n]  = SHA-256(tip[n-1] || seq || timestamp || ssrc || crc)
```

定期的にMerkle Rootを生成し、ブロックチェーンに記録する。アーティスト側も同じチェーンを構築するため、両者のRootが一致すれば「確かに聴いた」ことが第三者検証可能となる。これにより、**再生回数の不正が不可能**になり、サブスクリプション収益の分配根拠が透明化される。

### 2.3 Relay Network

音声パケットを中継するノードがP2P配信ネットワークを構成する:

| ティア | 役割 |
|--------|------|
| Origin | アーティスト/配信者の送信元 |
| Region | リージョン間の中継 |
| Edge   | ローカルエリアの配信 |
| P2P Swarm | リスナー同士の直接中継 |

Koeデバイス（$65）をWi-Fiに繋ぐだけでEdgeノードとなり、ネットワークの拡張に貢献できる。中継への貢献はアプリ内ENAIポイントとして記録される。

### 2.4 ファンランク

PoLで証明された再生回数に応じて、リスナーのファンランクが上昇する:

```
ランク         累計再生回数     特典
ビギナー       0+              基本視聴
レギュラー     10+             限定コンテンツ閲覧
コアファン     100+            先行試聴・限定チャット
スーパーファン  1,000+          バックステージ映像・クレジット掲載
レジェンド     10,000+         アーティストとの直接交流権
```

**早期から聴いていたファンほど高いランクを獲得できる。** ファンランクは金銭的リターンではなく、アーティストとの関係性を深める仕組みである。

## 3. エコノミクス

### サブスクリプションモデル

| プラン | 月額 | 内容 |
|--------|------|------|
| Free | ¥0 | 広告付き・月20時間まで |
| Pro | ¥500/月 | 広告なし・高音質・無制限 |
| Studio | ¥2,000/月 | Pro全機能 + アーティスト配信ツール + 分析 |

### アーティスト収益分配

サブスクリプション収益プールをPoLで検証された再生回数比率で分配する:

```
総収益プール = 全サブスクリプション収入 × 70%
アーティストAの報酬 = 総収益プール × (Aの検証済み再生回数 / 全体の検証済み再生回数)
```

- **アーティスト**: 70%（PoL検証済み再生比率で分配）
- **プラットフォーム運営**: 20%
- **ネットワーク維持**: 10%

従来のプラットフォームではアーティスト取り分が30%程度だったのに対し、Solunaでは**70%がアーティストに直接還元**される。

### ENAIポイント

ENAIはアプリ内ポイントであり、暗号通貨やトークンではない。

- **獲得方法**: 視聴時間、リレーネットワーク貢献、コミュニティ活動
- **利用方法**: 限定コンテンツの解放、ファンランクのブースト、アーティストへのチップ
- **制限**: 外部送金不可、換金不可、金銭的価値なし

### ブロックチェーンの役割: 透明性の担保

ブロックチェーンはアーティストへの支払いの透明性を担保するためだけに使用する:

- PoL Merkle Rootの公開記録（再生回数の第三者検証）
- 収益分配レポートの公開監査ログ
- 誰でも検証可能な支払い証跡

**ブロックチェーン上でのトークン発行・取引・NFT売買は行わない。**

### 価値の循環

```
リスナー → 聴く → PoL → ファンランク上昇
           ↓
         サブスク収益 → 再生比率で分配 → アーティスト報酬
           ↓
         Relay Node → 中継 → ネットワーク拡張
           ↓
         全員に価値が循環
```

### オンチェーン機能（透明性監査のみ）

1. `SubmitProof` — PoL Merkle Root提出（再生証明の公開記録）
2. `PublishDistribution` — 収益分配レポートの公開（誰でも検証可能）

## 5. なぜ今か

- **QUIC** [RFC 9000] のUnreliable Datagram拡張が2024年に標準化され、UDPとQUICの統一プロトコル設計が初めて可能になった
- 音楽業界の**ストリーミング収益分配**への不満が臨界点に達している
- ブロックチェーンの透明性技術が成熟し、**支払い監査**に低コストで活用できるようになった

## 7. 結論

Solunaは音楽のための電力網である。発電（アーティスト）、送電（リレーノード）、計量（PoL）をプロトコル層で実現し、サブスクリプション収益を検証済み再生回数に基づいて透明に分配する。

聴くほど、ファンランクが上がる。中継するほど、ネットワークが強くなる。作るほど、正当な報酬が届く。

これが、音楽が本来あるべき姿である。
