Soluna

オープンソース ネットワークオーディオシステム

プロ品質の低遅延オーディオストリーミングを、無料で。
ESP32、Raspberry Pi、PC間でシームレスに音声を伝送。

今すぐ始める GitHub

特徴

超低遅延

有線LANでサブミリ秒（1ms未満）のレイテンシ。リアルタイムモニタリングやライブパフォーマンスに最適。

PTPv2 同期

IEEE 1588-2008準拠のPrecision Time Protocolで、複数デバイス間でサンプル精度の同期を実現。

WiFi対応

FEC（前方誤り訂正）とアダプティブビットレートで、ワイヤレスでも安定したストリーミング。

マルチプラットフォーム

Linux、macOS、Windows、Raspberry Pi、ESP32をサポート。異なるデバイス間で自由に通信。

AES67互換

DanteやRavennaなどの業務用機器と相互運用可能。既存環境への導入も簡単。

完全オープンソース

MITライセンスで完全無料。ソースコード公開、改変・再配布自由。

クイックスタート

インストール

Linux (Debian/Ubuntu)

# ワンラインインストール
curl -sSL https://soluna.dev/install.sh | sudo bash

macOS (Homebrew)

brew tap soluna/tap
brew install soluna

ソースからビルド

git clone https://github.com/example/soluna.git
cd soluna
mkdir build && cd build
cmake .. -DCMAKE_BUILD_TYPE=Release
make -j$(nproc)
sudo make install

基本的な使い方

送信側（音源）

# マイク入力をネットワークに送信
solunad --tx --device hw:0 --dest 239.69.0.1:5004

受信側（スピーカー）

# ネットワークから受信して再生
solunad --rx --device default --port 5004

設定ファイルを使用

# YAML設定ファイルで詳細設定
solunad --config /etc/soluna/config.yaml
