What is OpenSonic? An open-source audio streaming system that sends system audio from a Mac (or any source) to iPhones, Raspberry Pis, browsers, Windows PCs, Android devices, and ESP32 microcontrollers with ~20ms latency. The underlying transport is OSTP — an RTP-based UDP protocol with FEC, NACK, swarm distribution, and protocol-level economics.

OSTP Protocol

The Open Sonic Transport Protocol (OSTP) is a UDP-based audio transport built on RTP (RFC 3550). It is specifically designed for large-scale one-to-many live audio distribution — a use case not well served by WebRTC (small groups, bidirectional conferencing) or AES67 (professional LAN studio routing).

Three Core Innovations

Innovation Description
Swarm Distribution Listeners optionally become relay nodes. 3-tier cascade + fan-out 4 P2P swarm supports up to 3 billion simultaneous listeners.
Economic Layer Protocol-level micropayments, royalty distribution (rights holder 70% / platform 10% / DJ cashback 20%), and copyright fingerprinting — all without an application-layer intermediary.
Channel Addressing Simple channel-name scheme compatible with both LAN multicast and WAN P2P — no IP address configuration required on the receiver side.

Packet Format

OSTP Packet (UDP payload)
┌────────────────────────────────────────────────────────┐
│  RTP Base Header       12 bytes  (RFC 3550)            │
│  RTP Extension Header   4 bytes                        │
│  OSTP Extension Block   8 bytes  (flags, channel ID,   │
│                                    economic fields)     │
│  Audio Payload          variable  (Opus / PCM / FLAC)  │
│  CRC-32 Trailer         4 bytes                        │
└────────────────────────────────────────────────────────┘

Quick Start

Mac (installer)

curl -LO https://github.com/yukihamada/opensonic/releases/latest/download/Soluna-mac.pkg
open Soluna-mac.pkg
# Allow driver: System Settings → Privacy & Security
# Set output: System Settings → Sound → Output → "Soluna"
# Open /Applications/Soluna.app → enable "Audio TX"

Build from Source

git clone https://github.com/yukihamada/opensonic.git
cd opensonic
cmake -B build -DSOLUNA_BUILD_TESTS=ON
cmake --build build --parallel
ctest --test-dir build --output-on-failure

Raspberry Pi / Linux

sudo bash deploy/rpi/install-rx.sh
soluna-rx --peer <mac-ip>:5099 --output alsa
