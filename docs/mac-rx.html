FEATURES

Everything you need

Professional audio quality with zero configuration

📡

Sync Mode & Jam Mode

Two modes: Sync Mode aligns all speakers for perfect multi-room playback. Jam Mode prioritizes ultra-low latency for real-time sessions. Switch with one click.

🌐

Stream Over the Internet

Not just WiFi — connect speakers worldwide via peer-to-peer. Play music across any distance.

🎤

Bi-Directional Audio

Full duplex audio — everyone sends and receives. In Jam Mode, latency drops to ~20ms for real-time jam sessions, lessons, and live collaboration worldwide.

🎵

Studio Quality

48kHz / 24-bit default. Supports 16/24/32-bit PCM lossless, Opus low-latency, and FLAC compression.

⚡

Zero Configuration

Bonjour auto-discovery finds devices instantly. Just connect and they appear. Auto-reconnect built in.
