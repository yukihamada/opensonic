FEATURES

Everything you need

Seamless network audio with zero configuration

📡

Multicast RTP/OSTP

Automatically receives audio streams on 239.69.0.1:5004. Zero configuration — just start and listen.

🔍

Bonjour Auto-Discovery

Finds Soluna transmitters on your local network automatically. No manual IP setup needed.

🔊

Multi-Speaker Control

Control multiple speakers from one place. Adjust volume, mute, and delay independently or all at once.

⚡

Auto-Sync

Measures round-trip time to automatically synchronize audio latency across all speakers.

🛡

Packet Loss Compensation

Built-in PLC algorithm fills in lost packets to keep playback smooth on congested networks.

📊

Real-time Statistics

Monitor packets, drop rate, buffer, and PLC count in real-time. Know exactly what's happening.

🎧

Bluetooth & AirPlay Sync

Add Bluetooth, AirPlay, or USB speakers and play them all in perfect sync. Each device gets its own AudioUnit with independent volume and delay.

🎯

Measured Latency Sync

Real-time latency measurement with EMA smoothing. Automatically compensates for BT (~40-200ms) and AirPlay (~2000ms) transport delays.

📊

VU Meter

Real-time RMS/Peak level meter for every output at 20fps. Green, orange, red color coding shows signal health at a glance.

⏱

Manual Delay Offset

Fine-tune sync with a ±50ms per-device delay slider. Saved automatically, perfect for room-specific adjustments.

💾

Routing Presets

Save your speaker configurations as named presets. Switch between “Living Room”, “Bedroom”, or “Party” setups with one tap.

🔗

Mac-to-Mac P2P Relay

Bonjour + UDP relay between Macs. When multicast can't reach across subnets, one Mac relays packets to others automatically.

🔄

Auto-Reconnect

Automatically reconnects when network returns. Uses NWPathMonitor to detect connectivity changes.

⌨️

Keyboard Shortcuts

Space to play/stop, ⌘↑↓ for volume, ⇧⌘M to mute, ⇧⌘S to sync. Full control without touching the mouse.

🎛️

3-Band Parametric EQ

Per-device 3-band EQ (200Hz/1kHz/5kHz, ±12dB). Tune each speaker independently for the perfect sound.

⏺️

Audio Recording

Record incoming audio to WAV files (48kHz/16-bit). Non-blocking ExtAudioFile writes from the audio thread.

📊

Spectrum Analyzer

32-band FFT spectrum display powered by Accelerate vDSP. Real-time frequency visualization with logarithmic band mapping (20Hz-20kHz).

🎚️

Compressor / Limiter

Per-output dynamics compressor with threshold, ratio, attack, and release controls. Prevent clipping and tame transients on any speaker.

📂

Preset Import / Export

Export routing presets to JSON files and import them on other Macs. Share your perfect speaker setups easily.

⭐

Favorite Devices

Star your favorite speakers. They auto-connect when plugged in or powered on — no manual setup each time.

🎵

Now Playing & Siri

Media key support via MPRemoteCommandCenter plus Siri Shortcuts. Control playback from your keyboard, Touch Bar, or voice.

👥

Speaker Groups

Group speakers into named zones like “Kitchen” or “Upstairs”. Control volume and mute for the whole group at once.

🌐

HTTP Remote API

Built-in REST API on port 9400. Control from Stream Deck, Home Assistant, curl, or any HTTP client. JSON responses with CORS.

🎼

Crossover & Spatial Audio

LPF/HPF crossover filter for sub/satellite splitting, plus stereo spatializer with width control and HRTF-inspired cross-feed for headphones.

🎚️

Sample Rate Display

Shows each device's native sample rate as a badge (44.1kHz, 96kHz, etc.). Instantly see format compatibility at a glance.

🔈

Multi-Channel Surround

5.1 and 7.1 surround sound support with channel layout display (FL, FR, C, LFE, SL, SR). Full immersion beyond stereo.

🔀

L/R Balance & Exclusive Mode

Per-device constant-power L/R panning. Plus USB DAC hog mode to block other apps from the output device.

📈

Latency Graph

Real-time line chart showing per-device latency trends. Spot network issues before they affect your listening.

🔌

Hot-Plug & Persistence

Instantly detects BT/AirPlay connect and disconnect. Enabled devices and offsets are saved to UserDefaults and restored on launch.

🖥️

Menu Bar Player

MenuBarExtra keeps Soluna in your menu bar. Quick access to status, volume, sync, and playback without opening the main window.

HOW IT WORKS

Three simple steps

Get whole-home audio running in minutes

1

Install Soluna TX

Set up the Soluna transmitter (solunad) on your source Mac. It captures system audio via a virtual driver.

→
2

Open Soluna Rx

Launch Soluna Rx on any Mac on the same network. It auto-discovers the transmitter and starts receiving.

→
3

Enjoy Music

Audio plays through your Mac speakers in perfect sync. Add more speakers and control them all from one place.
