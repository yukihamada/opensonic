Features

Everything you need for seamless network audio

📡

Multicast RTP/OSTP

Automatically receives audio streams on 239.69.0.1:5004. Zero configuration required — just start and listen.

🔍

Bonjour Auto-Discovery

Finds Soluna transmitters on your local network automatically. No manual IP configuration needed.

🔊

Multi-Speaker Control

Control multiple speakers from one place. Adjust volume, mute, and delay for each speaker independently or all at once.

⚡

Auto-Sync

Measures WebSocket round-trip time to automatically synchronize audio latency across all speakers.

🛡️

Packet Loss Compensation

Built-in PLC algorithm fills in lost packets to keep playback smooth even on congested networks.

📊

Real-time Statistics

Monitor packet count, drop rate, buffer size, and PLC count in real-time. Know exactly what's happening.
