Mac スピーカー
機能

必要なものは全部入り。

プロ向けのネットワークオーディオ機能を、オープンソースで。

⚡

低遅延配信

UDP マルチキャストで LAN 内 20ms 以下の遅延。Mac スピーカーと同期。

🔄

自動遅延同期

WebSocket RTT 計測で Mac スピーカーと iPhone の音を自動ピッタリ合わせ。

🛡

PLC パケット補間

最大 2 パケット欠落を前フレームで補完。WiFi でもプツッとしない。

📡

Bonjour 自動検出

同じ WiFi の iPhone が solunad を自動発見。IP アドレスを入力不要。

🌐

Web ダッシュボード

localhost:8400 で全操作。スパークライン、遅延バー、リアルタイム統計。

⚙️

設定の永続化

音量・遅延・ミュートを自動保存。再起動後も設定を引き継ぎ。

🖥

Menu bar アプリ

macOS メニューバーからワンタップで音量・遅延を調整。

🚀

launchd 自動起動

Mac ログイン時に自動起動。一度設定すれば意識しなくていい。

インストール

使い始めるのは簡単。

プラットフォームを選んでセットアップを始めてください。

💻

Mac 送信側 TX

まずここから。Mac がオーディオの送信元になります。

curl -fsSL https://soluna-web.fly.dev/install.sh | bash
詳細なセットアップ手順 →
📱

iPhone 受信側 RX

Mac と同じ WiFi に繋ぐだけで自動検出。

TestFlight で入手 →

Mac の Xcode でビルドする方法はこちら。

🥧

Raspberry Pi 受信側 RX

ワンコマンドインストール。ALSA DAC に対応。

sudo bash deploy/rpi/install-rx.sh
RPi セットアップ →
🌐

ブラウザ インストール不要

Mac で solunad が動いていれば、ブラウザから即試聴。

Dashboard を開く →

Dashboard の「Browser」タブから ▶ ボタンを押すだけ。
