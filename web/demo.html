How It Works

WebSocket + ADPCM Decoder

This demo runs entirely in-browser with no external imports. It connects to the Soluna relay via WebSocket, decodes ADPCM audio from RTP/OSTP packets, and plays back through the Web Audio API at 48kHz.

// 1. Connect via WebSocket const ws = new WebSocket(`wss://relay.solun.art/ws/audio?channel=${name}`); ws.binaryType = 'arraybuffer'; // 2. On message: parse RTP/OSTP header, decode ADPCM, play ws.onmessage = (e) => { const data = new Uint8Array(e.data); const payload = parseRTP(data); // strip header + CRC const pcm = decodeADPCM(payload); // IMA ADPCM → Int16 // 3. Play via Web Audio API const buf = ctx.createBuffer(1, pcm.length, 48000); const ch = buf.getChannelData(0); for (let i = 0; i < pcm.length; i++) ch[i] = pcm[i] / 32768; const src = ctx.createBufferSource(); src.buffer = buf; src.connect(ctx.destination); src.start(nextTime); };
