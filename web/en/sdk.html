OVERVIEW

What is Soluna SDK?

Just a few lines of code to turn your app into a live audio platform.

A battle-tested SDK used in both the Koe app and the Soluna app. Proven reliability in production environments.

Uses BSD Sockets directly with OSTP/RTP protocol for low-latency real-time audio communication. By adopting raw UDP sockets instead of NWConnection, full protocol-level compatibility is guaranteed.

Supports SwiftUI's @ObservableObject. Connection state and receiving status are reactively reflected in the UI with a modern Swift design.

QUICK START

Get Started in 5 Lines

Import and connect. That's all it takes to receive audio.

import SolunaSDK

let client = SolunaClient()

// Connect to a channel
client.connect(channel: "my-channel")

// Switch channels
client.setChannel("sunset-chill")

// Disconnect
client.disconnect()
SWIFTUI

SwiftUI Integration

Simply declare as @StateObject and connection state is reactively reflected in the UI.

import SwiftUI
import SolunaSDK

struct MyPlayerView: View {
    @StateObject private var soluna = SolunaClient()

    var body: some View {
        VStack {
            Text(soluna.isConnected ? "Connected" : "Offline")
            Text(soluna.isReceivingAudio ? "♫ Playing" : "Silent")

            Button(soluna.isConnected ? "Stop" : "Play") {
                if soluna.isConnected {
                    soluna.disconnect()
                } else {
                    soluna.connect(channel: "soluna")
                }
            }
        }
    }
}

API REFERENCE

Key APIs

Properties and methods provided by SolunaClient.

isConnected

Connection state to the relay server. Bindable to SwiftUI via @Published.

@Published Bool

isReceivingAudio

Whether audio packets are being received. Use for playback state display in the UI.

@Published Bool

channel

The currently connected channel name. Auto-updated on connect and switch.

@Published String

connect(channel:)

Connect to a channel and start receiving audio. Custom host / port can also be specified.

Method @MainActor

setChannel(_:)

Switch to a different channel. Automatically executes disconnect then connect internally.

Method Auto-reconnect

disconnect()

Disconnect from the relay and stop audio playback. Safely cleans up resources.

Method Cleanup
