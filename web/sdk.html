OVERVIEW

Soluna SDK とは

たった5行のコードで、あなたのアプリがライブ音声プラットフォームになる。

Koe アプリと Soluna アプリの両方で使われている、実績あるSDK。プロダクション環境で検証済みの信頼性。

BSD Socketを直接使用し、OSTP/RTPプロトコルで低遅延のリアルタイム音声通信を実現。NWConnectionではなく生のUDPソケットを採用することで、プロトコルレベルでの完全な互換性を保証。

SwiftUIの @ObservableObject に対応。接続状態や受信状態がリアクティブにUIへ反映される、モダンなSwift設計。

QUICK START

5行で始める

インポートして、接続するだけ。それだけで音が届く。

import SolunaSDK

let client = SolunaClient()

// チャンネルに接続するだけ
client.connect(channel: "my-channel")

// チャンネルを切り替え
client.setChannel("sunset-chill")

// 切断
client.disconnect()
SWIFTUI

SwiftUI との統合

@StateObject として宣言するだけで、接続状態がリアクティブにUIへ反映される。

import SwiftUI
import SolunaSDK

struct MyPlayerView: View {
    @StateObject private var soluna = SolunaClient()

    var body: some View {
        VStack {
            Text(soluna.isConnected ? "Connected" : "Offline")
            Text(soluna.isReceivingAudio ? "♫ Playing" : "Silent")

            Button(soluna.isConnected ? "Stop" : "Play") {
                if soluna.isConnected {
                    soluna.disconnect()
                } else {
                    soluna.connect(channel: "soluna")
                }
            }
        }
    }
}

API REFERENCE

主要なAPI

SolunaClient が提供するプロパティとメソッド。

isConnected

リレーサーバーへの接続状態。@Published で SwiftUI にバインド可能。

@Published Bool

isReceivingAudio

音声パケットを受信中かどうか。UIでの再生状態表示に使用。

@Published Bool

channel

現在接続中のチャンネル名。接続・切替時に自動更新。

@Published String

connect(channel:)

チャンネルに接続して音声受信を開始。host / port のカスタム指定も可能。

Method @MainActor

setChannel(_:)

別のチャンネルに切り替え。内部で disconnect → connect を自動実行。

Method Auto-reconnect

disconnect()

リレーから切断し、音声再生を停止。リソースを安全にクリーンアップ。

Method Cleanup
